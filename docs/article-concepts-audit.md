# Revisión de conceptos y enlaces entre artículos

Revisión del 18 de octubre de 2026. Se recorren las 499 rutas de artículos y sus plantillas, incluidos los tres capítulos de integración y textos dinámicos de laboratorios.

**Resultado:** 65 artículos nuevos e independientes, 1462 enlaces de conceptos en texto estático y 65 asociaciones explícitas para texto dinámico. Se conserva el contenido matemático de los artículos anteriores y no se insertan enlaces dentro de fórmulas, encabezados, controles, código, bibliografías o enlaces existentes.

Los 94 temas de la auditoría anterior tienen un destino. Se agrupan conceptos estrechamente relacionados cuando comparten fundamentos; M67 reutiliza el artículo de grafos ya existente. Los términos ambiguos (por ejemplo Cauchy, Euler, grado, norma, anillo o nodo aislados) no se enlazan por coincidencia ciega. La selección es editorial: no presupone que cualquier palabra matemática necesite una página propia.

## Estructura y mantenimiento

Cada artículo nuevo posee componente, plantilla, estilos, estado y cálculo del laboratorio. Reutiliza infraestructura general de fórmulas y gráficas. La herramienta de autoría en scripts/article-foundations no es un registro de ejecución. El menú y las rutas usan los catálogos temáticos existentes.

Los enlaces de texto dinámico usan un componente genérico que recibe texto y una lista explícita de destinos del consumidor; no interpreta HTML ni consulta un glosario global. Se conservan los modelos independientes de los artículos.

Validación: npm run test:article-concepts, npm run test:article-navigation, compilación de desarrollo y npm run test:article-concepts:browser. El detalle legible por máquina está en article-concept-coverage.json.
