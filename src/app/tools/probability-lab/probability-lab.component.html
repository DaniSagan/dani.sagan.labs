Intervalos {{knownSigma?'Z con desviación conocida':'t con desviación estimada'}}. Su cobertura es exacta bajo normalidad; en otras poblaciones se explora su aproximación. Para Cauchy no existe una media poblacional que cubrir. El nivel de confianza describe el procedimiento en repeticiones, no la probabilidad de una media fija después de observar el intervalo.

El bootstrap remuestrea las observaciones disponibles con reemplazo. El intervalo percentil es una aproximación; con pocas observaciones, sesgo, dependencia o colas extremas puede tener mala cobertura.

Se usan los grupos 0 y 1 y una prueba bilateral: (1 + réplicas con |d*| ≥ |d observado|) / (B + 1). Requiere intercambiabilidad bajo la hipótesis nula; un p-valor no es P(H₀ | datos).
