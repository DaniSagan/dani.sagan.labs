Un lote con dos piezas defectuosas

Probabilidad · Conteo y probabilidad condicionada

Enunciado

Un lote de 8 piezas contiene 2 defectuosas. Se eligen 3 sin reposición, uniformemente entre todos los subconjuntos. Calcula la probabilidad de exactamente una defectuosa.

Solución paso a paso

  1. Como no importa el orden, contamos subconjuntos. El total de elecciones es C(8,3)=8·7·6/(3·2·1)=56.
  2. Para tener exactamente una defectuosa elegimos una de las dos defectuosas: C(2,1)=2 opciones. Las otras dos piezas deben salir de las seis buenas.
  3. Elegir dos buenas tiene C(6,2)=6·5/2=15 posibilidades. Cada elección de defectuosa se combina con cada par bueno: 2·15=30 casos favorables.
  4. La probabilidad es 30/56=15/28≈0,5357. La cuenta no supone independencia: la ausencia de reposición se incorpora al elegir subconjuntos del lote.

Resultado. 15/28≈53,57%.

Error frecuente. Usar probabilidades constantes en tres ensayos independientes modelaría una extracción con reposición.
