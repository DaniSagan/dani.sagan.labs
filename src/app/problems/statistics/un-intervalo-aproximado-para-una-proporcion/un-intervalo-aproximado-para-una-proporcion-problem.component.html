Un intervalo aproximado para una proporción

Estadística y lectura crítica de datos · Inferencia y muestreo

Enunciado

En una muestra aleatoria de 400 respuestas independientes, 240 son favorables. Construye el intervalo normal aproximado del 95% usando 1,96 y comenta su interpretación.

Solución paso a paso

  1. La proporción observada es p̂=240/400=0,6. Para esta aproximación estimamos su error estándar por √(p̂(1−p̂)/n).
  2. Sustituimos: √(0,6·0,4/400)=√0,0006≈0,024495. Hay 240 éxitos y 160 fallos, cantidades suficientemente grandes para usar esta aproximación habitual.
  3. El margen es 1,96·0,024495≈0,04801. Restamos y sumamos a 0,6: obtenemos aproximadamente [0,55199,0,64801].
  4. La cobertura del 95% se refiere al procedimiento repetido en muchas muestras bajo el modelo. No significa que el 95% de las personas esté dentro de un intervalo ni corrige un muestreo sesgado. La aproximación normal puede fallar cerca de 0 o 1 o con muestras pequeñas.

Resultado. Intervalo aproximado [0,5520,0,6480], o 55,20%–64,80%.

Error frecuente. El nivel de confianza no es una proporción de observaciones individuales.
