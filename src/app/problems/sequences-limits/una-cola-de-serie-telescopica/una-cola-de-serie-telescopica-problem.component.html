Una cola de serie telescópica

Sucesiones, límites y continuidad · Sucesiones y series

Enunciado

Calcula la suma desde n=1 hasta infinito de 1/((n+1)(n+2)) y el error tras N términos.

Solución paso a paso

  1. Separamos cada término: 1/((n+1)(n+2))=1/(n+1)−1/(n+2). Al reunir estas fracciones el numerador es (n+2)−(n+1)=1.
  2. La suma parcial es Sₙ=(1/2−1/3)+(1/3−1/4)+…+(1/(N+1)−1/(N+2)). Los términos interiores se cancelan.
  3. Queda Sₙ=1/2−1/(N+2). Cuando N crece, el último término tiende a cero, por lo que la suma infinita es 1/2.
  4. El error es la suma total menos la parcial: 1/2−Sₙ=1/(N+2). Es positivo porque todos los términos omitidos son positivos.

Resultado. Suma 1/2; error después de N términos: 1/(N+2).

Error frecuente. Una suma infinita se define mediante el límite de sumas parciales.
