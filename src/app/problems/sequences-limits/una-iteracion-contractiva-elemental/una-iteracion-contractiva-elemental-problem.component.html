Una iteración contractiva elemental

Sucesiones, límites y continuidad · Límites y continuidad

Enunciado

Con x₀=0 y xₙ₊₁=(xₙ+6)/4, encuentra el límite y un índice que asegure error menor que 0,001.

Solución paso a paso

  1. Si la sucesión tiene límite L, la recurrencia exige L=(L+6)/4. Resolver 4L=L+6 da L=2. Todavía debemos demostrar que realmente se aproxima a él.
  2. Restamos 2 a ambos lados: xₙ₊₁−2=(xₙ−2)/4. Cada paso reduce el error por un factor 4.
  3. Como x₀−2=−2, se deduce xₙ−2=−2/4ⁿ. Por tanto xₙ=2−2/4ⁿ y el error absoluto es 2/4ⁿ, que tiende a cero.
  4. Queremos 2/4ⁿ<0,001, o 4ⁿ>2000. Como 4⁵=1024 y 4⁶=4096, n=6 basta; el error es 2/4096≈0,000488.

Resultado. Límite 2; desde n=6 el error es menor que 0,001.

Error frecuente. Encontrar un posible punto fijo no demuestra por sí solo convergencia.
