Números taxicab: dos sumas de cubos y el caso 1729

¿Cómo puede un número escribirse como suma de dos cubos de dos maneras diferentes? La anécdota del taxi de Hardy y Ramanujan da una respuesta famosa. Aquí comprobamos sus cuentas y precisamos la propiedad matemática.

Un cubo no es una multiplicación por tres

Elevar un número a la tercera potencia significa multiplicarlo por sí mismo tres veces: 3³ = 3 × 3 × 3 = 27. En particular, 12³ = 1728, 9³ = 729 y 10³ = 1000. Así obtenemos:

  • 1³ + 12³ = 1 + 1728 = 1729.
  • 9³ + 10³ = 729 + 1000 = 1729.

Las parejas (1, 12) y (9, 10) son diferentes. Cambiar (1, 12) por (12, 1) no cuenta como una nueva representación: solo hemos intercambiado los sumandos. Para evitar duplicados escribimos siempre 1 ≤ a ≤ b y buscamos sumas a³ + b³.

Por qué importa que los enteros sean positivos

«Positivo» excluye tanto el cero como los negativos. Si permitimos números negativos aparece, por ejemplo, 91 = 3³ + 4³ = 6³ + (−5)³. Eso no contradice la propiedad de 1729: estamos usando otras reglas. Tampoco estamos buscando raíces reales arbitrarias; las bases de los cubos deben ser enteras.

Comprobar las dos igualdades no demuestra que sea el menor

Para demostrar que 1729 es el menor con dos representaciones necesitamos descartar todos los anteriores. La búsqueda puede hacerse finita y completa:

  1. Si a y b son positivos y a³ + b³ ≤ 1729, ninguno puede ser 13 o mayor, porque 13³ = 2197 ya supera el límite.
  2. Basta, por tanto, recorrer 1 ≤ a ≤ b ≤ 12. Son 1 + 2 + … + 12 = 78 parejas antes de descartar las sumas que exceden 1729.
  3. Calculamos cada suma permitida y agrupamos las parejas que dan el mismo resultado.
  4. La única suma repetida hasta 1729 es precisamente 1729, con las dos parejas anteriores. Todas las menores aparecen como máximo una vez.

¿Qué significa «número taxicab»?

En la convención habitual, Ta(n) es el menor entero positivo que puede escribirse como suma de dos cubos de enteros positivos de exactamente n maneras distintas, sin contar por separado el orden de los sumandos. Por eso Ta(1) = 2, mediante 1³ + 1³, y Ta(2) = 1729. Aunque sea el protagonista de la anécdota, 1729 no es el primer término de esta sucesión.

Existen otros números con dos representaciones. Por ejemplo, 4104 = 2³ + 16³ = 9³ + 15³. Lo que distingue a 1729 en este problema es ser el menor, no ser el único. Para exigir tres o más representaciones hay que investigar otros límites; la enumeración anterior solo resuelve el caso hasta 1729.
