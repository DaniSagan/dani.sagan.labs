Álgebra / raíces y parámetros

Una parábola, tres paisajes de raíces

Una ecuación cuadrática parece un problema de sustitución en una fórmula. Sin embargo, su estructura contiene más información que dos números: podemos saber cuántas raíces hay, dónde se sitúan, qué signos tienen y cómo cambian al mover un parámetro. El discriminante resume una transición geométrica; las relaciones de Viète permiten razonar sobre las raíces sin calcularlas. Combinar ambas miradas evita muchos cálculos y distingue una solución de una clasificación completa.

Completar el cuadrado explica la fórmula

Consideremos ax² + bx + c = 0 con coeficientes reales y a distinto de cero. Dividir por a no altera las soluciones. Añadir y restar el cuadrado de b/(2a) transforma la expresión en un cuadrado más una constante. Estamos trasladando el origen horizontal hasta el eje de simetría de la parábola.

Al igualar a cero, queda un cuadrado igual a Δ/(4a²), donde Δ = b² − 4ac. El denominador es positivo, de modo que el signo de Δ decide si ese cuadrado puede existir en los reales. Extraer la raíz produce dos signos, no solo el positivo.

El discriminante visto en la gráfica

Si Δ > 0, la parábola corta el eje horizontal dos veces. Si Δ = 0, el vértice toca el eje: hay una raíz doble, no dos distintas. Si Δ < 0, no hay cortes reales. El vértice tiene abscisa −b/(2a) y ordenada −Δ/(4a). Para a positivo abre hacia arriba; para a negativo hacia abajo. Cambiar el signo de todos los coeficientes invierte la gráfica, pero conserva las raíces.

Las raíces complejas no son un fracaso

Cuando Δ < 0, escribimos √Δ = i√(−Δ). Las raíces son conjugadas porque los coeficientes son reales: comparten parte real −b/(2a) y tienen partes imaginarias opuestas. Por ejemplo, x² − 2x + 5 = 0 da 1 ± 2i. La parábola real no corta el eje, pero el polinomio se factoriza sobre los complejos. El discriminante decide la naturaleza de las raíces dentro del universo que estamos usando.

Viète: sumar y multiplicar sin resolver

Si las raíces son r y s, a(x − r)(x − s) tiene coeficiente lineal −a(r + s) y término independiente ars. Comparar coeficientes da las relaciones de Viète.

Para raíces reales, un producto negativo implica signos opuestos. Si el producto es positivo, tienen el mismo signo, que determina la suma. Dos raíces reales distintas y positivas requieren simultáneamente Δ > 0, −b/a > 0 y c/a > 0. Ninguna condición sobra: una suma positiva puede acompañar a una raíz negativa, y un producto positivo puede corresponder a dos raíces complejas.

Resolver un problema con parámetro

En x² − 2αx + α + 2 = 0 buscamos dos raíces reales distintas y positivas. Su discriminante es 4(α − 2)(α + 1), positivo para α < −1 o α > 2. Viète da suma 2α y producto α + 2. La suma positiva exige α > 0; al intersectar todas las condiciones queda α > 2. En α = 2 las raíces son ambas 2: el extremo debe excluirse.

Degeneraciones y estabilidad numérica

Si a = 0, ya no hay una cuadrática. Si b ≠ 0 queda una ecuación lineal; si a = b = 0, un c no nulo hace imposible la igualdad y c = 0 la convierte en una identidad. Hay que separar estos casos antes de dividir por a. En una familia, perder el grado puede cambiar el número de soluciones abruptamente.

En un ordenador, la fórmula habitual puede perder cifras cuando −b y √Δ casi se cancelan. Para Δ > 0, una evaluación más estable calcula q = −(b + signo(b)√Δ)/2, tomando signo positivo para b = 0; obtiene una raíz como q/a y la otra como c/q. El laboratorio usa esta forma. Reduce la cancelación, pero no elimina el mal condicionamiento: cerca de una raíz doble, una pequeña perturbación de los coeficientes puede separar las raíces de forma relativamente grande.

Comprobar y explorar

Sustituir cada raíz verifica el cálculo; sumar y multiplicar verifica su estructura. Un residuo pequeño no garantiza muchas cifras correctas cuando la parábola es casi tangente al eje. La clasificación exacta debe hacerse con desigualdades exactas: las gráficas son una guía, no una demostración.
