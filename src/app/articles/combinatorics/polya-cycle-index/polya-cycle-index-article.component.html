Teorema de Pólya e índice de ciclos

Definición · Justificación · Ejemplo · Explorar · Ejercicio

Definiciones y alcance

Una permutación descompone las posiciones en ciclos disjuntos. Una coloración queda fija por esa permutación exactamente cuando cada ciclo es monocromático. El índice de ciclos de una acción finita promedia monomios que registran cuántos ciclos de cada longitud tiene cada elemento del grupo.

Por qué funciona y qué exige

Con q colores disponibles, una permutación con c ciclos fija qᶜ coloraciones. Promediar sobre el grupo es el lema de Burnside. El teorema de Pólya refina el conteo sustituyendo en cada variable del índice una suma de potencias de marcadores de color, lo que permite distinguir composiciones y no solo contar el total de órbitas.

Un ejemplo desarrollado

Para rotaciones de cuatro posiciones, el índice es (a₁⁴+a₂²+2a₄)/4. Sustituir cada aᵢ por q da (q⁴+q²+2q)/4 collares distintos bajo rotación. Con dos colores se obtienen seis. Si se identifican también reflejos, el grupo cambia y debe recalcularse el índice.
