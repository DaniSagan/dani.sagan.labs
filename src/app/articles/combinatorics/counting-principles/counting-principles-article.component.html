Contar exige definir qué objetos se consideran diferentes antes de aplicar una fórmula. Una contraseña, un comité y un reparto pueden usar los mismos nombres y producir cantidades distintas: importa si el orden cambia el resultado, si un elemento puede repetirse y si las decisiones se excluyen o se encadenan. Los principios de suma y producto son la base lógica de esas diferencias; combinaciones y permutaciones se deducen de ellos.

Alternativas disjuntas y decisiones sucesivas

El principio de suma cuenta alternativas que no pueden ocurrir simultáneamente. Si una elección puede hacerse por dos vías y ambas incluyen el mismo objeto, sumar sus tamaños duplica ese objeto. El principio de producto cuenta procesos por etapas: cada resultado de la primera debe admitir el mismo número de continuaciones para multiplicar por una constante. Si las ramas tienen tamaños diferentes, se suma el número de hojas de cada rama. Dibujar un árbol pequeño evita confundir estas situaciones.

Repetir elementos y conservar el orden

Una palabra de longitud fija sobre un alfabeto permite reutilizar símbolos; cada posición constituye una decisión independiente de las anteriores. Elegir personas distintas para cargos diferentes reduce las opciones disponibles después de cada elección. El orden distingue presidente y secretario, aunque ambos pertenezcan al mismo conjunto de personas. Una permutación completa utiliza todos los elementos exactamente una vez. El caso de ninguna elección contiene un único resultado, el vacío, que explica el factorial de cero.

Olvidar el orden mediante una relación de equivalencia

Cada subconjunto de tamaño fijo aparece tantas veces en la lista ordenada como maneras hay de ordenar sus miembros. Dividir por ese número funciona porque todas las clases tienen el mismo tamaño. Esta justificación es esencial: al identificar rotaciones de un collar, las clases pueden tener tamaños distintos y la misma división deja de ser válida. Las combinaciones con repetición constituyen otro problema, que puede transformarse en distribuir objetos indistinguibles mediante separadores.

Restricciones y conteo complementario

Si el requisito es incluir al menos un elemento especial, resulta más sencillo contar todas las elecciones y restar las que no contienen ninguno. Las probabilidades uniformes se obtienen dividiendo casos favorables entre posibles, pero solo después de verificar que todos esos resultados elementales tienen la misma probabilidad. Una lista de tipos de resultados, como tener cero, uno o dos éxitos, normalmente no es equiprobable. El conteo construye el espacio muestral; no establece por sí solo su distribución.

Demostrar la identidad de Pascal

Clasifica los subconjuntos de tamaño k según contengan o no un elemento distinguido. En el primer caso quedan k menos uno miembros por escoger entre los demás; en el segundo se escogen k entre esos mismos elementos. Son casos disjuntos y exhaustivos, así que el principio de suma produce la identidad de Pascal. Esta prueba también explica por qué las filas del triángulo de Pascal sirven para expandir una potencia: cada término corresponde a elegir en qué factores aparece la segunda variable. Para contar repartos indistinguibles, una fila de k estrellas y n menos uno separadores representa las cantidades entregadas a n receptores; escoger posiciones de estrellas da combinaciones con repetición.

Un ejemplo resuelto

Entre ocho personas, tres son especialistas. Formar un comité de tres con al menos un especialista da todas las combinaciones menos las que usan únicamente a las cinco restantes. Si además se asigna un cargo diferente a cada miembro, cada comité produce seis equipos ordenados.

Laboratorio y comprobación

Compara los tres conteos para la misma cantidad de opciones. Predice qué ocurre al elegir un solo elemento y al elegir todos. El cociente entre selección ordenada y no ordenada debe ser el factorial del número de elementos elegidos.

Hipótesis y errores frecuentes
