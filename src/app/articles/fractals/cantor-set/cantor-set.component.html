Conjunto de Cantor

El conjunto de Cantor nació en 1883 en el trabajo de Georg Cantor sobre los fundamentos de los números reales. Su construcción parece una simple operación de borrar, pero desmonta varias expectativas: el resultado contiene infinitos puntos, es no numerable como todo el intervalo real y, a pesar de ello, tiene longitud total cero. Cantor lo usó para estudiar qué significa realmente un conjunto infinito; hoy es una puerta de entrada especialmente clara a los fractales.

Se parte del intervalo cerrado [0,1] y se retira su tercio abierto central. Quedan [0,1/3] y [2/3,1]. A cada intervalo superviviente se le quita de nuevo el tercio central, y el procedimiento no termina. Tras n iteraciones existen 2n intervalos, cada uno de longitud 3−n. La longitud conservada es (2/3)n, que tiende a cero. La dimensión fractal resume este equilibrio: log(2)/log(3), cerca de 0,631.

También puede describirse con números: un punto pertenece al conjunto si admite una expansión ternaria que usa solo los dígitos 0 y 2. Cambiar 0 por 0 y 2 por 1 revela una correspondencia con secuencias binarias infinitas. Esta lectura explica por qué hay tantos puntos aunque no quede ningún tramo completo de longitud positiva.

El explorador dibuja cada barra y se llama dos veces para sus tercios exterior izquierdo y derecho. Prueba varias iteraciones: los huecos aumentan, pero la regla nunca dibuja un vacío arbitrario. Es una visualización directa de cómo una definición recursiva puede codificar un objeto infinito.
