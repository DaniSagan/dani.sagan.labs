Las visitas incluyen las posiciones iniciales y las casillas de llegada. Un paso es un movimiento de una hormiga; no una ronda completa. Retroceso: últimos 100.000 movimientos. El plano no tiene bordes; visitas e historial consumen memoria. Cada lote cede el control al navegador entre fotogramas.
¿Y si cambiamos el tablero inicial?

La semilla reproduce la distribución aleatoria. Dibujar o recolocar una hormiga establece una nueva condición inicial y reinicia el contador. «Reiniciar» recupera esa condición.

Para pintar, toca una casilla y arrastra: el primer toque decide si pintas o borras. Con teclado puedes usar las coordenadas y estos botones.

Comparar dos condiciones iniciales

A conserva tu condición inicial; B empieza con el preset elegido. Se reinician ambos contadores para comparar el mismo tiempo.

Para comparar una sola perturbación usa A blanco y B con una casilla. Ajusta la región para observar las diferencias en coordenadas comunes.
