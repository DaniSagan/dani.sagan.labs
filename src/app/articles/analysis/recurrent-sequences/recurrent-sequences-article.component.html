Sucesiones recurrentes: alcanzar un punto fijo

Una regla aplicada una y otra vez puede acercarnos a un equilibrio, alejarnos de él o encerrarnos en un ciclo. La ecuación del equilibrio es solo el comienzo. Para demostrar convergencia hay que controlar todo el recorrido: dónde permanece, en qué dirección avanza y cuánto reduce cada paso la distancia.

1. El límite debe respetar la regla

Si aₙ₊₁ = f(aₙ), la sucesión converge a L y f es continua en L, entonces L = f(L). Resolver esa ecuación produce candidatos; no demuestra que se alcance alguno.

Un contraejemplo. aₙ₊₁ = 1 − aₙ tiene punto fijo 1/2. Desde a₀ = 1 alterna entre 1 y 0 y no converge.

2. La sucesión radical: encerrar y avanzar

Con a₁ = 1 y aₙ₊₁ = √(2 + aₙ), el intervalo [1, 2] es invariante: si un término está dentro, el siguiente también. Para 1 ≤ x ≤ 2, √(2 + x) ≥ x porque (2 − x)(x + 1) ≥ 0.

3. Una recurrencia afín se vuelve geométrica

Para aₙ₊₁ = αaₙ + β, con α ≠ 1, restar el punto fijo elimina la constante.

Si |α| < 1, cualquier inicio converge; α negativo produce oscilaciones amortiguadas. Si |α| > 1, cualquier inicio distinto de L se aleja. Para α = 1, aₙ = a₀ + nβ. Para α = −1 aparece generalmente un ciclo de dos términos.

En el problema 043, α = 1/3, β = 2 y a₀ = 5. Así, aₙ = 3 + 2/3ⁿ.

4. Contracciones y una cota de error

En un intervalo cerrado invariante, si |f(x) − f(y)| ≤ q|x − y| con 0 ≤ q < 1, el teorema de Banach garantiza un único punto fijo y convergencia desde cualquier inicio del intervalo. También convierte una diferencia entre iteraciones en una cota del error restante.

Para la raíz en [1, 2], f′(x) ≤ 1/(2√3). Para una función con derivada continua cerca de L, |f′(L)| < 1 asegura atracción local, no convergencia desde cualquier punto lejano.

5. Iteraciones en un ordenador

Se necesita una tolerancia y un máximo de pasos. Dos términos redondeados iguales no prueban error cero. En varias variables, los valores propios describen la estabilidad lineal local; cerca de fronteras de estabilidad hace falta estudiar órdenes superiores.
