Una prueba que sigue a tu grafo

Edita las aristas o elige otro vértice de partida. El argumento encuentra un triángulo en cada coloración.

Desde {{ labels([pivot]) }} salen cinco aristas. Cada una es roja o azul; no queda ninguna pareja sin conectar.

Al repartir cinco aristas entre dos colores, al menos tres comparten color. Elegimos las {{ witness.red ? 'rojas' : 'azules' }} hacia {{ labels(witness.chosen) }}.

Ahora miramos las tres aristas que unen {{ labels(witness.chosen) }} entre sí. Si alguna es {{ witness.red ? 'roja' : 'azul' }}, cierra un triángulo con {{ labels([pivot]) }}. Si ninguna lo es, las tres tienen el otro color.

{{ labels(witness.triangle.vertices) }} forman un triángulo {{ witness.triangle.red ? 'rojo' : 'azul' }}. {{ witness.matching === undefined ? 'Ningún lado entre los tres vecinos coincide con las aristas de partida: el triángulo aparece entre ellos.' : 'Un lado entre dos vecinos coincide con las aristas de partida: el triángulo incluye el vértice inicial.' }}
