U(−1, 1): media 0 y varianza 1/3. La anchura se reduce aproximadamente como 1/√n; la referencia normal es asintótica y es poco precisa para n = 1.

En cada muestra se genera un único U(−1, 1) y se repite n veces. La media es ese mismo valor: no hay concentración. La anchura teórica es 1,6 para cualquier n.

La media de n Cauchy estándar independientes sigue siendo Cauchy estándar. Su esperanza y su varianza no existen. La anchura teórica es 2 tan(0,4π) ≈ 6,155 para todo n.
